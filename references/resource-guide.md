# 工具与模块素材：按需使用

这里只定义执行入口，证据、数据与图表专项规范仍是权威规则。模板字段及图形示例按本次研究问题和可得资料调整，不作为固定业务格式。

## 按任务选择资源

| 需要 | 读取／使用 | 不自动发生 |
|---|---|---|
| 摸清项目及 Excel 对象 | `scripts/inventory.py` | 不改原件，不启动 Excel，不获取外部链接 |
| 批量保存指定 PDF 页码 | `scripts/capture_pdf.py` | 不替用户判读证据，不做 OCR，不自动写正文或 Excel |
| 检查本地引用、文件变化及截图嵌入 | `scripts/check_delivery.py` | 不修复文件，不核验来源真实性，不把计数相同当保真 |
| 建立字段与留证登记 | [素材：登记与证据](../assets/登记与证据模板.md) | 不强制每字段一张表，不编造公开来源 |
| 选底稿组织方式 | [素材：Excel模块](../assets/Excel模块示例.md)，及[数据规则](data.md) | 不照搬整本目录，不自动重构已有 Excel |
| 实际操作的可编辑参考 | [Excel模块演示.xlsx](../assets/Excel模块演示.xlsx) | 示例为虚构数据，不能作为研究证据 |
| 复用Excel基本图表外观 | `scripts/excel_chart_style.mjs`及[图表规则](charts.md) | 不自动选指标、切换图形或改动图源 |

scripts 使用 Python 3.10+；清点和本地核对仅依赖标准库。PDF 工具另需 `pypdf`、Poppler 的 `pdftoppm`；裁切需 Pillow。优先使用当次运行环境已提供的运行时，不硬编码本机安装路径，不自动安装依赖。读写权限仍以用户任务及环境为准。

图表样式辅助代码供JavaScript导入，接收已创建且已绑定图源的`@oai/artifact-tool`图表。示例：`applyBasicChartStyle(chart, {kind: 'line', palette: ['#C00000'], numberFormat: '0.0'})`。柱形示例用`kind: 'bar'`；组合、饼图等按表格工具文档另外配置，不假称此函数能处理所有类型。

## 运行约定

以下路径是参数示意，替换为实际、已授权的位置。报告路径必须尚未存在；不覆盖旧报告。运行前确保输入已保存稳定，不要让脚本输出进入它正在扫描的目录。Python 应使用 `-B` 避免在 skill 目录生成缓存。

```text
python -B scripts/inventory.py --input "项目/数据底稿.xlsx" --input "项目/正文.md" --out "审查/清点-修改前.json"
python -B scripts/inventory.py --root "项目" --out "审查/项目清点.json"

python -B scripts/capture_pdf.py --pdf "项目/support/原始资料/报告.pdf" --pages "2,5-7" --source-id S01 --source-url "真实原始网址" --out "项目/support/证据截图/S01-新批次"
python -B scripts/capture_pdf.py --pdf "报告.pdf" --pages "5" --source-id S01 --crop "0.05,0.2,0.95,0.8" --printed-page-note "PDF第5页对应印刷第3页" --out "截图/S01-裁切新批次"

python -B scripts/check_delivery.py links --root "实际Obsidian主库" --note "项目/正文.md" --note "项目/资料底稿.md" --out "审查/引用核对.json"
python -B scripts/check_delivery.py compare --before "审查/清点-修改前.json" --after "审查/清点-修改后.json" --protect "正文.md" --out "审查/变更核对.json"
python -B scripts/check_delivery.py evidence --registry "项目/数据证据登记.json" --out "审查/截图嵌入核对.json"
```

`--protect` 使用清点报告的精确 `key`。同一根目录清点时为相对路径；按文件清点时为绝对路径。前后清点需使用同种范围和标识；迁移项目时可分别按两侧根目录清点，按相对位置比较。新增或变化不自动视为错误，须比对获准范围；受保护文件变化或输入失败返回非零退出码。

## 三个工具的具体边界

### 清点

清点文件大小与 SHA-256；XLSX／XLSM 只读解析实际有值／公式的单元格、共享公式元数据指纹、原生图表、图片、来源引用、冻结、合并和缓存错误等。声明的使用范围可能包含格式残留，不能拿它当有效数据量。XLS／XLSB 仅做文件指纹，不声称完成结构解析。

目录扫描不跟随目录联接或符号链接，跳过隐藏配置目录和 Excel 临时锁文件。必要资料若位于联接目标中，明确授权后用 `--input` 指定真实文件。读取失败逐项记录；扫描期间发生变化的文件需重新清点。结构检查不重算公式、不校验经济含义，也不等于视觉检查。

### PDF 留证

`--pages` 一律是从1开始的 PDF 阅读器页序，不能用印刷页码代替；对应关系用注记保存。指定裁切时仍保留完整页，登记矩形、DPI、原始网址、源文件和图像指纹。输出只能是新批次目录，失败保留已完成页及失败记录，不覆盖旧图。脚本没有联网行为；本地来源没有公开网址就省略该参数。

生成截图后仍要检查标题、表头、单位和注释是否完整，再选入证据卡；数据截图另嵌入 Excel。PDF 文字识别和网页截图不在此工具内，按当次可用技能处理。

### 交付核对

- `links` 识别 Obsidian 双链及简单 Markdown 内联引用，排除代码示例；区分文件存在、同名歧义、缺失／超出扫描范围、外链未联网检查。锚点与块编号只标“尚未核验”，不冒称完整 Obsidian 链接验证。复杂括号、引用式链接及插件解析留人工复核。
- `compare` 对比文件指纹、工作表及公式变化、图表／图片绘图引用、媒体内容指纹；同数量替换截图也能发现媒体内容差异。变化只表示需按范围审阅，不能单凭 XML 不同推断丢失或损坏。
- `evidence` 按登记检查外部截图是否以相同字节嵌入指定工作表；图片重新编码后无法精确匹配时标“未确认”，不能断言没嵌入。只找到图片不说明其支持了该范围数字，也不代替原文判断。

缺证据、扫描失败、未执行的重算和未核验的显示，必须在交付中如实保留，不能合并成“全部通过”。

## 可继续积累的参考
