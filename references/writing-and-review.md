# 正文、局部修订与整理（M06／M08／M09）

## 写成报告

正文围绕研究问题形成连续论证，采用“判断—证据—解释—衔接”，不把资料卡拼成正文。开头只放理解研究必要的背景；具体材料归入能够支撑的论点。主线已确认时，增补内容归入原结构，不借机重写框架。

- 结论清楚，语言简练有力；删除同义重复、资料堆积和防御式措辞，保留真正影响判断的限制。
- 图表靠近相关论点，说明它证明什么、变化意味着什么。同一数据可以服务不同分析，但不重复讲同一背景。
- 重要主体首次出现点明身份、必要名称沿革与关系；历史和现时架构标日期。资本市场研究不按名称推定控制或一致行动关系。
- 新事实先落实原文、准确定位及截图；新数字先核对原数和公式，再更新对应图文。证据缺失时不把推断写成事实；缺口集中留底稿。
- 重要事实链接到具体证据卡，数据图注明 Excel 文件、工作表和范围；卡片记录正文位置。正文保留读者必须知道的限定，底稿承担详细核验边界。
- 末尾只列实际采用的参考资料，写清全名、发布者、日期／版本、原始链接及本地入口，保留既有原始链接。不把材料库全部文件抄作参考文献。

同步写作时一次闭合一节及其资料、数据和图表；已有核验证据直接复用。发现缺口按已授权组合补齐，不重建无关底稿。

## 局部修改按问题处理

| 变化 | 核对什么 | 不默认做什么 |
|---|---|---|
| 纯措辞精简 | 原意、上下文、保护项与事实是否改变 | 重新取数、出图、全文重写 |
| 新增事实／原文 | 来源、证据卡、截图和对应表述 | 改其他章节框架 |
| 更新数字／期间 | 原数、公式、采用版本和关联图文 | 重算无关数据和图表 |
| 替换图表 | 图源、截图、图注、正文引用和旧版留存 | 重做全部图表 |
| 变更标题／路径 | 受影响双链、锚点、目录及图片引用 | 移动无关文件 |
| 整理底稿 | 原内容和媒体保留、导航与定位有效 | 改只读正文 |

修改前保留合适的可恢复版本或变更记录，不必每次复制整个项目。保护已确认框架、用户原文、加粗高亮、指定图表、原始链接、元数据原值和稳定编号。

## 按定稿整理底稿

1. 正文只读，提取章节及实际采用的证据、数据和图表映射。
2. 按正文证据顺序分组并完善目录；证据编号、工作表名和锚点不因重排而变。现行、补充和历史材料分别导航，不删除未采用原始资料。
3. Excel 整理先清点对象，分区分表需避免重复原数或破坏公式、原生图表、图片和链接。数据表太大时可用标题和描述分区，不为视觉整齐重造整本工作簿。
4. 核对本轮影响的链接、图片显示、原文定位、数据与计算、图源和引用一致性。保真不只比较数量，必要时核对内容和媒体。
5. “正文未改”等声明须有相应核验；只整理底稿时可比较正文指纹，普通润色检查保护项即可，不把全库指纹当常规硬步骤。

## 范围外影响与交付

数据更新而正文未获准修改时，指出受影响的具体引用位置；底稿可区分当前计算与正文采用版本，旧图不能冒充新图。重大框架调整、新主题或触及明确保护项时，先交具体方案；已授权的直接依赖继续完成。

只检查时交问题与建议，不自动修订。只润色时交指定位置的改动，不扩大为全文审校。最终简述修改范围、核验结果和未完成项，提供实际文件入口，不用冗长过程记录替代结果。
