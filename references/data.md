# 数据底稿（M04；M07 的图源核验）

本文件规定取数、留证及按模块组织底稿的原则；具体排版、命名和分册阈值仍可细化。已有工作簿沿用其有效结构，未经授权不重排。

## 先明确需求

每组数据先明确：支撑的判断、指标定义、对象／地区／产品、期间与频率、单位、分母及报表范围。先核查已有资料、招股书、年报、统计披露和数据库导出，不因最新文件发布而覆盖解释历史机制所需数据。

数据库暂不可访问时可交数据需求表，写清数据库／功能、对象代码、指标全称、起止日期、频率、报表口径、单位与导出格式。区分“需求已规划”和“数据已取得核验”，不能假称已访问数据库。

## 按分析模块组织工作簿

### 表头与指标按情景确定

**模板中的表头、业务指标、时间方向及行列顺序均为示例，不是固定字段。**先依据研究问题和可得资料选择指标，再确定表头；公司跟踪可用营收、产量、成本，行业专题可用供需、库存和价格，测算可用相应驱动变量。年份、季度、主体也可按比较和更新需要横向或纵向排列。

保持一致的是信息职责：对象、期间、单位及口径可辨，原数与假设／计算可区分，来源和截图可定位，图源可追溯。这些信息可写在标题、数据区旁或共用说明中，不要求每项各占一列。资料没有的指标不为凑模板编造；确有分析用途时再补取或说明缺口。新数据揭示更合适的指标时，在获准范围内调整，已有工作簿不因模板不同就重构。

### 模块的选择

**默认以能共同回答一个研究问题、解释一个主体或完成一条计算链的数据组为组织单元，不以一项指标或一张图作为固定分表单位。**先确定模块及依赖，再决定同页分区、独立工作表或必要分册。下列是可组合的模式，不是固定版式或必须建齐的目录。

| 本次任务 | 优先组织方式 | 何时拆分 |
|---|---|---|
| 专题／行业／产业链研究 | 按需求、供给、成本、竞争、技术等实际分析模块分表；同一模块可含多组相关数据、测算、图表及来源 | 模块有独立问题或数据更新流程，或明细及截图已明显妨碍阅读时拆分 |
| 主体跟踪与比较 | 公司／项目明细与跨主体比较相配合；侧重单一主体时按主体分表，侧重横向比较时按指标模块分表，必要时组合并设统一汇总 | 某主体明细或测算确有独立维护需要时拆分；不能为每个主体、每项指标各复制一套相同原数 |
| 驱动测算模型 | 按完整计算链或独立业务模块组织，关键参数、计算步骤及结果保持可顺序阅读；简短模型可同页完成并配少量图表 | 计算链较复杂或存在多个独立子模型时，拆分假设、计算和汇总，但明确相互引用；不按每个中间变量拆表 |
| 定期图表库 | 按指标模块或可独立维护的图表单元组织；需要逐图更新、导出和稳定定位时可一图一表，相关图共享同一数据组 | 只有独立更新、展示或导出确有用途时按图拆分；不能将一图一表推广为所有研究底稿的默认结构 |

### 分区、拆表与时间跨度

- 同一问题下口径可比、更新方式接近的数据优先同表分区；用标题、单位、时期和必要空白区分，保持时间列及主体标识对齐。模块太杂、滚动查找困难或更新相互独立时再拆表。不为了凑固定页数、工作表数或每表图数拆分。
- **时间跨度长本身不是拆表理由。**一条长期序列可保留完整历史并单独定义展示窗口；高频大表可放原数明细表，模块内引用必要汇总和图源。模型需要连续期间时保留计算链，不按年份随意切断；频率不同且用途不同的数据可分区或分表，并说明汇总关系。
- 原数、假设、计算、结果、图源与证据是职责，不要求各建一张表。同页时明确分区；多表时指向权威原数和计算位置。图表可放模块结果附近或统一展示区，不为出图复制原数。
- 来源和数据截图尽量靠近对应数据组；过多或过大的截图可放本工作簿的模块证据区／证据表，写清双向定位。仍须保留外部截图并实际嵌入工作簿，不改成只贴链接。
- 复杂底稿保留简洁导航，标明模块用途、关键范围、数据截止期、来源及依赖；主体披露进度不一致时记录各自更新状态。小底稿无需为几行说明新增目录表。
- 新建或获准重构前，简述所选模块、分表理由及原数到结果的关系；已授权范围内直接执行。需求与现有模式不匹配时组合、调整或重新设计最简结构，不硬套。模板不适配不自动触发用户确认，也不构成重排已有文件的授权。

## 原数、计算、来源分工

- 原始文件只读，保留原名、原单位、原值、披露精度和版本日期；清洗、换算和计算放工作底稿。
- 原数为可计算单元格。比例、合计、差额及换算使用可追溯公式，注明分子、分母、单位因子和统计范围，不手工覆盖计算结果。
- 图表引用计算区或图源区；同组数据一处维护、多图引用。需要分册时保留统一入口和权威数据位置。
- 来源落实到原始文件及页码，或导出文件、工作表和范围；转引、估算及预测标明发布者、日期、版本和必要假设。
- 数据截图保存为外部文件，并实际嵌入相关工作簿，登记对应数据范围和证据卡。图片链接、超链接或路径不等于嵌入；截图不能代替数值与公式。
- 大表可分段截图，保留表头、单位和必要注释，重叠部分不重复取数。复用已有外部截图，不重复造文件。

## 口径核对

| 容易混淆的项目 | 处理要求 |
|---|---|
| 年度、半年、季度；期间、时点 | 先核对再比较；半年不自动年化，存量不跨期加成流量 |
| 合并、母公司；含税、不含税 | 明确报表范围和定义，不混接序列 |
| 产品规格、现货价、合约价 | 记录可比规格和价格类型，不能只因名称相近就拼接 |
| 空缺、未披露、不适用、0 | 分别表达，“—”不未经核实变为0 |
| 历史实际、机构预测、自有估算 | 分列或显著标识，保留原始版本；预测不伪装成实际 |
| 投资额、注册资本、股数、账面收益、现金回收、担保 | 区分概念；不能仅凭持股比例推算累计实际出资 |
| 市场需求份额、厂商份额；产量、产能 | 标清分母和统计对象，不直接混比 |

重述或更新保留旧值与采用理由。展示可四舍五入，原数和计算精度保留。

## 试行登记字段

```text
支撑问题／正文位置：
指标／对象／期间／频率／单位／分母／报表范围：
原始来源、版本及定位：
原数范围／计算范围／图源范围：
外部截图／工作簿内截图位置／证据卡：
采用版本、缺口与核验结果：
```

这些字段按数据组登记，可在模块内复用共同来源，不要求每项指标单独建表。只整理数据不自动出图。

## 完成条件

原数可定位、公式可复算、口径可解释、截图实际嵌入，数据与来源一致；核对实际保存后的工作簿，而非只检查生成脚本。创建或编辑 Excel 使用当次适用的表格技能，做必要计算与视觉核验。

结构核对看能否顺畅找到同一模块的数据、计算、图表和证据；测算链是否连贯；更新是否只需维护一处权威数据；既无无用碎表，也无难以区分的混杂大表。不要把工作表少或每表图少当成合格标准。

编辑已有工作簿前清点工作表、公式、原生图表、嵌入图片和链接，采用能保留这些对象的方法。不为整理外观而整本重导出导致对象丢失；无法保留时保留原件并如实提出可行处理方式。
