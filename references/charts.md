# 图表制作（M07）

先写清这张图要支持的一个判断，再决定是否需要新图。图表用于论证和理解，不为增加图表数量制作。优先沿用用户提供的底稿样式；没有明确样式时采用下述Excel基本数据图表风格，尺寸及导出规格按用途调整。

## 图源选择

- **可靠原数可得**：优先在 Excel 自绘，保留可编辑原生图表、引用数据、公式与原始来源，导出清晰图片用于正文。数据底稿规则同时适用。
- **只有原图或原图信息不可替代**：可直接引用原图，标注来源；完整原页在资料底稿留证，涉及数字时还嵌入 Excel。不从曲线补造精确观测数据。
- **关系／机制／架构图**：保留可编辑来源和每条关键关系的事实依据，不强迫所有关系图用 Excel；标明结构时点，区分股权、控制、出资、担保和业务关系。

## 选型与编排

按判断选择最直接的图形，不将某案例的饼图、双轴或组合图固化为通用要求。趋势图核对频率、缺口和预测分界；结构占比核对分母及类别是否互斥穷尽；组合图只在同图能帮助解释关系时使用。

图表数量不决定工作表数量。专题或主体跟踪中，相关图表归入对应分析模块或共享展示区，共用权威图源；模型图放在相关结果附近，不拆散参数和计算链。逐图独立更新／导出的图表库才按需要采用一图一表。长历史数据与展示窗口分别管理，不因为图只显示近期就截去原数；具体分区及拆表依据见[数据底稿](data.md#按分析模块组织工作簿)。

标题、时期、轴单位、图例、分母、预测标记和来源齐全。双轴标识清楚；不凭两条线同涨同跌推断因果。重要变化由正文简短解释，并与本节论点相连。

## Excel基本图表风格

参考底稿体现多种样式，不将其中一本的字体或配色强制套用全部项目。优先使用可编辑、直接绑定单元格的Excel原生图表：

| 分析目的 | 常用图形 | 关键处理 |
|---|---|---|
| 主体、时期或规模比较 | 簇状柱形／横条图 | 柱轴从0起；同一系列同色，排名可排序 |
| 价格、库存、产销等趋势 | 折线图；不规则时间间隔必要时用散点连线 | 日期按顺序；保留缺测间断；密集序列少用标记 |
| 规模与增速／利用率共同分析 | 柱形＋折线组合图 | 仅确有联读价值时采用；左右轴各标单位和系列；不暗示因果 |
| 构成、份额或供给来源 | 堆积柱形；类别少时可用饼图 | 核对分母、类别和合计；不为了展示类型增加图 |

- 默认透明底：图表区（Chart Area）和绘图区（Plot Area）均显式设为无填充，不用白色实心填充替代。导出PNG保留透明通道，并检查实际图像背景，不能仅凭白色工作表预览判断透明；只有用户明确要求时才使用实色底。无渐变和3D；采用细灰坐标轴与少量浅灰水平主网格线，避免厚边框和装饰底色。图例通常置上或下，单系列可省略。
- 从参考底稿选一致配色。常用候选为深红`#C00000`、蓝`#0070C0`／`#4472C4`、灰`#9FA7B2`；当前期或关键系列可用深红，比较期用蓝灰。颜色含义跨图保持一致，不要求每图三色齐全。
- 中文字体沿用项目；新建无指定时可用微软雅黑，数字及英文字体可沿用参考样式。标题、轴、图例均显式设置可读字体，不能仅改单元格字体。短数据序列可显示小标记和关键标签，长序列避免逐点标数。
- 原数保留精度，坐标轴与标签设置合适显示精度；单位写在标题或轴上。预测用文字／线型区分；不存在的数字不因模板留空位就填0。

可编辑示例见[模块演示](../assets/Excel模块演示.xlsx)。需要复用样式代码时可用`scripts/excel_chart_style.mjs`，仅调整明确支持的外观，不选指标、不改图源、不替代图形选择。参数可覆盖默认配色、字体和精度；按当次表格技能使用兼容工具并核验实际导出。

## 可追溯交付

图号／名称 → 正文位置 → 导出图片 → Excel 图表或其他可编辑源 → 图源区／公式 → 原始来源、证据卡和截图，保持能相互定位。已有编号与文件名尽量稳定，新版图不覆盖旧图源。

仅要求预览时，交预览和必要图源，不自动插入正文；获准插入后检查实际显示。Excel 有图不代表正文图表已交付。更新数据时核对图表实际引用范围，不能只改标题日期。

验收：图数一致，图像清晰，无截字遮挡，历史与预测可辨，源文件可编辑，图注来源可查。报告只完成本轮所需的图表，不声称全报告重做或核验完成。
